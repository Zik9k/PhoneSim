# PhoneSim

Симулятор телефона в браузере: **Android + iPhone**, мини-игры и ссылки в реальные магазины.

## Открыть
https://zik9k.github.io/PhoneSim/

Или скачай файлы и открой `index.html`.

## Что есть
- Переключатель **Android / iPhone** (разный UI)
- Несколько моделей корпусов
- **Play Store / App Store** — встроенные игры + кнопки на реальный Google Play / App Store
- Мини-игры: Cookie Clicker, Idle Gems, Mine Click, Rocket Idle, Space Shooter, Zombie Wave, Tap Arena, Drift Sim

## Важно
Полноценный Google Play / App Store со всеми играми внутри сайта **невозможен** (ограничения платформ).
Внутри — HTML5-игры; «Открыть» ведёт на настоящую страницу игры в магазине.
